# So you want to build a Virtual Machine Monitor

We're gonna be getting into the basics of hypervisors and KVM and by the end of this chapter you will be able to run a tiny kernel on a single core virtual machine that you made using KVM yourself!

This book expects you to be comfortable with C and Linux, know what a syscall is and have KVM available on your machine. Although I'll try my best to explain all the little things, it will be a much faster and smoother experience if you already have some familiarity with these concepts.
